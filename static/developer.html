⚙️ Technical Architecture & Engineering Specifications

🔬
VeritasCore Engine
  • Automated open ArXiv API query decomposition and paper retrieval.
  • Structured extraction: Objective, Methodology, Key Findings, Constraints.
  • Evidence DNA grounding linking every factual assertion to verbatim passages.
  • Automated Claim-Level Verification Audit flagging unsupported or contradictory findings.
🤖
Autonomous Multi-Agent System
  • Dynamic Orchestrator decomposing broad research queries into targeted sub-tasks.
  • Concurrent parallel worker agents conducting multi-source literature review.
  • Synthesizer agent compiling cohesive research reports with inline citations.
  • Adversarial Critic agent enforcing strict factual grounding and completeness.
💻
Full-Stack Implementation
  • FastAPI & Uvicorn asynchronous backend with real-time SSE streaming.
  • Serverless SQLite persistent database with indexed session history CRUD.
  • Zero-dependency modern vanilla JavaScript frontend with live state management.
  • Multi-provider LLM support: local Ollama, Google Gemini API, and demo fallback.
📊
MLflow LLMOps & Telemetry
  • Structured experiment telemetry logging model parameters and execution timing.
  • Automated tracking of Evidence Integrity scores, supported/unsupported claim ratios.
  • Artifact logging for full research markdown, Evidence DNA maps, and audit logs.
  • Pre-configured for cloud container deployment on Netlify, Render, and Docker.
